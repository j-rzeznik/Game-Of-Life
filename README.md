# Game-Of-Life

Repozytorium zawiera projekt realizowany w ramach przedmiotu "programowanie komponentowe". Powstał on na platformie Bitbucket, we współpracy z Klaudią Łuczak (kluczak12). 
Projekt miał na celu utworzenie aplikacji realizującej graficzną symulację "gry w życie". 
Powstawał w okresie 10.2024 - 01.2025

Aplikacja umożliwia:
- tworzenie, zapis i odczyt stanu planszy, zarówno poprzez operacje na plikach, jak i przy użyciu lokalnej bazy danych
- zmianę stanu planszy w dowolnym momencie symulacji
- określenie wymiarów planszy oraz gęstości aktywnych komórek
- wybór języka w interfejsie graficznym - polski lub angielski

Aby projekt działał prawidłowo, konieczne jest uruchomienie lokalnej bazy danych, która w tym przypadku została zrealizowana przy użyciu środowiska Docker.
